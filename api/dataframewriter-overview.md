title: DataFrameWriter Reference
---

The `OpenEphys.Onix1.DataFrameWriter` namespace contains operators for saving
[DataFrames](xref:data-elements) to disk in the [Apache Arrow IPC file
format](https://arrow.apache.org/docs/format/Intro.html). Arrow is a columnar,
self-describing binary format natively supported by Python, R, Julia, and
Matlab, among others.

> [!TIP]
> See the [DataFrameWriter tutorial](xref:data-frame-writer) for a
> step-by-step guide on using these operators in an acquisition workflow and
> loading the resulting files in Python.
